01 — CAREER

Професійна мета

Прагну розпочати професійну кар'єру в IT на позиції Junior JavaScript Developer / Trainee JavaScript Developer. Зацікавлений у проходженні стажування, де зможу застосувати отримані під час навчання знання на практиці, працювати над реальними програмними продуктами та отримати досвід командної розробки.

Основний напрямок професійного розвитку — JavaScript / TypeScript, React та Node.js. Маю базові знання програмування, алгоритмів і структур даних, роботи з базами даних та вебтехнологіями. Прагну поглиблювати знання сучасного JavaScript-стека, розвивати навички написання якісного та підтримуваного коду й поступово перейти від рівня Junior до Middle та Senior Developer.

Зацікавлений у роботі над frontend та fullstack-проєктами, створенні вебзастосунків, REST API, роботі з базами даних та інтеграції клієнтської і серверної частин.
